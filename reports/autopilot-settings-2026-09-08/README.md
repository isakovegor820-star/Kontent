# Настройки автопилота — 8 сентября 2026

## Исправления

- В «Настройки → Автопилот» вся форма доступна сразу после загрузки канала. Она также остаётся открытой после сохранения и смены канала.
- Кнопка «К настройкам» прокручивает к форме и переводит фокус на переключатель; при входе страница сама не прокручивается.
- В основном разделе автопилота максимальное число событийных постов и подпись «из N» соответствуют частоте выбранного канала.
- Ссылка из параметров плана открывает «Настройки → Автопилот» для того же канала.

## Проверка передачи параметров

Форма получает конфигурацию через `GET /api/settings/channel`, сохраняет автопилот через `POST /api/autopilot/settings`. Основной экран получает ту же запись `autopilot_settings` через `GET /api/autopilot`. Чтение и запись ограничены выбранными проектом и каналом.

| Настройка | Использование |
| --- | --- |
| Включение | Фоновое планирование, пауза и возобновление автоматического восстановления частичного плана |
| Постов в неделю | Количество публикаций и расписание |
| Период | Горизонт плана; число публикаций = частота × недели |
| Свежие события | Целевое число событийных постов, ограниченное общим числом публикаций |
| Объём | Желаемый диапазон длины в запросе к генератору |
| Подача | Инструкция о спокойном, разговорном или живом стиле |
| Эмодзи | Политика эмодзи и допустимое количество |
| Модель | Основной генератор постов и предусмотренный резерв при недоступности |

Настройки фиксируются в снимке при создании плана. Изменения действуют на следующую сборку; уже созданный план не переписывается. Для плана из утверждённой месячной кампании частота берётся из кампании, горизонт такой сборки — одна неделя.

## Автоматические проверки

143 теста прошли: форма, сохранение и ошибки, переключение каналов, API чтения/записи/генерации, снимок настроек в очереди, параметры текста, планирование и контракты обработчика. ESLint изменённых файлов прошёл без замечаний.

Браузерный сценарий: `scripts/test-autopilot-settings-e2e.mjs`. Он использует отдельную тестовую PostgreSQL, отдельную Redis и `npm run dev` с полноценным обработчиком `autopilot-plans`. Внешние HTTP-запросы стенда заблокированы; реальные публикации и генерация у платных провайдеров не запускаются.

## Ограничения проверки

Браузерный сценарий не завершился: на локальном стенде истекло ожидание формы (включая повтор с лимитом 120 секунд). Его нельзя считать успешной проверкой сохранения через реальную базу. Скриншоты успешного сценария не получены. В начале запуска Turbopack также отклонил ссылку на общие зависимости соседней рабочей копии; повторный стенд запускался через webpack.

Полная production-сборка была остановлена при длительной компиляции, чтобы освободить ресурсы для браузерной проверки. Тестовые процессы остановлены, созданные стендом база и Redis удалены. Рабочие данные не менялись.

Изменения подготовлены в ветке `codex/autopilot-settings-20260908`. На рабочий сайт не опубликованы.

Проверка TypeScript (`tsc --noEmit --incremental false`) прошла после удаления временных артефактов незавершённого dev-запуска. Настройки TypeScript проекта восстановлены без изменений.
