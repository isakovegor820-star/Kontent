# Проверка календаря автопилота — 7 сентября 2026

Реализованы раскрывающийся календарь с неделей и месяцем, просмотр полного поста, выбор отдельных постов и всех готовых, ручное подтверждение добавления, возврат из редактора с сохранением контекста и перенос времени той же публикации.

## Проверки

- 231 тест в 28 файлах: автопилот, API, редактор, транзакционное планирование, форматирование, блокировки публикаций и Telegram multipart/carousel.
- Дополнительно проверен существующий API переноса publication operations.
- `npx tsc --noEmit` — без ошибок.
- ESLint изменённых компонентов, обработчиков и библиотек — без ошибок.
- Браузер: Chrome, 1440×1100 и 390×844; ошибок JavaScript нет.
- Сохранение форматирования проверено до конечного Telegram payload.
- Повтор подтверждения и устаревшие версии черновика/расписания не создают дубли и не перезаписывают актуальный пост.
- Изменение текста с повторной проверкой качества, медиа и форматирование покрыты тестом API; атомарная запись медиа и payload — тестом планировщика.

Браузерные результаты: [e2e-results.json](e2e-results.json).

## Среда и границы проверки

`npm run dev` запущен вместе с полным worker; у очереди `autopilot-plans` подтверждён активный worker. Использовались отдельная временная PostgreSQL-база и Redis. Внешние HTTP-запросы заблокированы; реальная отправка в Telegram и внешние ИИ-сервисы не выполнялась. Тестовая среда остановлена после проверки. На production изменения не развёрнуты.

## Повторный запуск

Из корня репозитория запустить `node scripts/autopilot-qa-runtime.mjs`, дождаться `ready: true`, затем в другом терминале `node scripts/test-autopilot-calendar-e2e.mjs`. Runtime требует локальный PostgreSQL, Redis из Homebrew и Google Chrome. После проверки остановить runtime через SIGTERM/Ctrl+C для удаления его временной базы и Redis.
