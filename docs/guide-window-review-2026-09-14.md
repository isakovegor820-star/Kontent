# Окно гида: перемещение, размер и свободная компоновка

## Scope and Coverage

Consolidated `better-interface` review, режим `full`. Область: окно гида, его шапка, прокручиваемое содержимое, управление размером и связь с существующим поиском/обучением. Использованы все шесть interface skills. Стек и общие цветовые/типографические токены Авроры сохранены.

| Domain | Проверено | Результат |
| --- | --- | --- |
| Accessibility | Native buttons, подписи, focus-visible, стрелки/Shift/Home, Escape, live region, pointer cancellation | Перемещение и размер доступны с клавиатуры; Escape сначала отменяет жест. Основные контролы 44 px, дополнительный верхний угол 24 px. |
| Layout | 440 × 580 по умолчанию; ограничения viewport/safe area; обе ручки; свёртывание; сохранение; 320–1440 px и landscape | Отдельные шапка/подвал и прокручиваемое тело; окно остаётся внутри экрана. |
| Writing | Названия действий, подсказки жестов, сброс, инструкции для клавиатуры | Короткие русские подписи; «Сбросить вид» восстанавливает размер и положение. |
| Typography | Рендер обеих тем, переносы 320 px, заголовок, описание, шаги | Согласованы локальные h2/h3 tokens с глобальной типографикой приложения; текст не сдавливает контролы. |
| Colors | Общие surface/text/border/info tokens, обе темы, forced-colors styles | Сохранена семантическая палитра; общий тест text/surface даёт минимум 5.40:1 в светлой и 6.95:1 в тёмной теме. Это измерение общей палитры, а не всех пар окна. |
| UI | Pointer capture, оба угла, touch-action, обычное/reduced motion, видимые ручки, hover/focus | Прямая манипуляция без задержки CSS transition; новые автономные анимации не добавлены. |

## Findings

| Приоритет | Причина | Исправление и повторная проверка |
| --- | --- | --- |
| High | Фиксированное тесное окно нельзя разместить рядом с нужным содержимым | Перетаскивание за шапку, два угла изменения размера, сохранение и сброс. Browser drag/resize/persistence проходят. |
| Medium | Глобальная reduced-motion длительность превращала изменение координат в transition и давала отставание от указателя | Отключён transition-property только для геометрии guide stage/panel; повторный browser test проходит. |
| Medium | Глобальные важные h2/h3 правила перекрывали локальный размер шрифта, сжимая шапку на 320 px | Использованы локальные typography tokens; повторно проверены desktop и dark 320 px снимки. |

Открытых подтверждённых замечаний в этой области после исправлений нет.

## Considered but Rejected

- Анимация самостоятельного движения гида: запрос решён управляемым перемещением окна; постоянное движение мешало бы читать объяснение.
- Изменение только CSS `resize`: не обеспечивает одинаковое сенсорное/клавиатурное управление, сохранение и ограничение видимой областью.
- Исправление карточек календаря: фоновые предупреждения вызваны неполными синтетическими fixtures; горизонтальная ширина календаря при 390/768 px воспроизводится и без discovery UI. Это отдельная область.

## Verification

- ESLint изменённых JS/TS файлов и `tsc --noEmit --incremental false`: passed.
- Vitest: 3 файла, 25 тестов passed, включая 7 проверок геометрии и повреждённых настроек.
- `AURORA_DISCOVERY_BASE_URL=http://localhost:3103 node scripts/test-discovery-browser.mjs`: passed. 10 сочетаний ширины/темы, мышь, клавиатура, отмена жеста, оба угла, сворачивание, сохранение после закрытия/перезагрузки, сброс, границы viewport, CDP touch emulation, landscape 640 × 320 и существующие сценарии поиска/обучения. JS page errors: 0.
- Runtime: `npm run dev` запускает web и полный BullMQ worker; проверка использует отдельную локальную БД/Redis. Browser API responses синтетические, записи в реальные аккаунты не выполнялись.
- Визуально просмотрены desktop, mobile, dark 320 px и walkthrough снимки в `reports/discovery-guide-2026-09-14/` (локальные артефакты).
- Not verified: физические мобильные устройства, VoiceOver/NVDA, настоящий browser zoom 200%, все возможные сочетания системного масштабирования/виртуальной клавиатуры. Проверка 320 px и landscape подтверждает reflow, но не заменяет эти проверки.

## Verdict

Approve для изменённого окна гида в проверенных сценариях. Публикация и серверные проверки фиксируются отдельно результатом штатного CI/deploy.
