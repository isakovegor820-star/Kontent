# Scope and Coverage

Режим full. Область: переход от карточек аналитического реестра раздела «Идеи и примеры» к выбранному пользователем варианту «Фокус» с фирменным синим Авроры. Стек: Next.js 16, React 19, Tailwind 4, общие Button, Lucide и существующие токены app-v3. Компонент подключён к LibraryRegistryView; схемы API, формулы, поиск, фильтры и экспорт сохранены. Отдельная вкладка «Коллекция» и отключённый legacy fallback не перерабатывались.
