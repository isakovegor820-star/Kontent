# План реализации живого маршрута Авроры

1. Добавить серверную проверку итоговой разметки второго варианта: три неинтерактивных маршрута, у каждого есть доступная подпись действия и декоративные линия с импульсом; старые элементы `hinge` и `marker` отсутствуют.
2. Заменить средний блок разметки на прозрачный `route` с линией, импульсом, подписью и наконечником.
3. Разделить красную и зелёную панели на самостоятельные рамочные объекты; убрать фон, рамку и тень с контейнера строки.
4. Настроить однократную последовательность: проявление линии, движение импульса, затем активация результата после прибытия сигнала. Анимировать только `transform` и `opacity`.
5. Развернуть маршрут вертикально на ширине меньше 768 px и определить статичное состояние для reduced motion.
6. Проверить в браузере 1440, 390 и 320 px, отдельно проверить отсутствие горизонтального переполнения и белой центральной поверхности.
7. Запустить целевой тест, полный набор Vitest, ESLint и production build. Если build блокируется несвязанным существующим кодом, подтвердить ошибку отдельной TypeScript-проверкой и зафиксировать её без изменения чужого участка.
